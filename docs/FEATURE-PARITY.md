# Feature comparison with commercial flyover apps

OpenFlyover's goal is to give everyone, for free, what paid flyover apps sell, built entirely
by us. We compare **features** using the apps' own public descriptions (support pages, store
listings). We never copy their code, designs, icons, text or assets, and never decompile them
(see PROMPT.md, "Hard rules").

Sources (checked 2026-10-16): Relive's public
[Plus features](https://support.relive.com/kb/guide/en/relive-plus-features-fQ8ISqSGRd/Steps/3655880),
[video customisation](https://support.relive.com/kb/guide/en/what-can-be-customised-in-a-relive-video-UERhY1BHbf/Steps/3682267)
and [app update](https://support.relive.com/kb/guide/en/your-new-relive-is-here-SkECJOTybj/Steps/4393615)
pages, and its home page.
